# Demons Roots - Traducción al Español

Parche de traducción al español para *Demons Roots* (RPG Maker, Steam). Toma como base la traducción de Kevklour (F95zone) y completa los textos que esa traducción había dejado sin traducir.

## Instalación

1. Aplica el [parche +18 gratuito de Kagura Games](https://www.kaguragames.com/product/demons-roots-patch/) para Demons Roots (Steam/GOG).
2. Copia todos los archivos de este repositorio dentro de `www\data` en tu instalación de Steam, reemplazando los archivos existentes:

```
...\steamapps\common\Demons Roots\www\data
```
